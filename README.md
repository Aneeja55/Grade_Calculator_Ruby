# Grade_Calculator_Ruby
This is a simple Ruby project I created while learning Ruby programming. The program takes marks for different subjects, calculates the total and average, and displays the final grade.

## Features
- Accepts marks for multiple subjects
- Calculates total marks
- Calculates average
- Displays grade based on average score

## Concepts Used
- Classes and Objects
- Arrays
- Loops
- Methods
- Conditional Statements
- User Input
